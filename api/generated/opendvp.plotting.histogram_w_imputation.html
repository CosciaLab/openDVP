opendvp.plotting.histogram_w_imputation#

histogram_w_imputation(adata_before_imputation, adata_after_imputation, n_cols=4, return_fig=False, save=False, save_name=None, **kwargs)#

Plot histograms for each sample showing raw and imputed values before and after imputation.

Return type:

Figure | None

Parameters#

adata_before_imputationAnnData

AnnData object with the raw data.

adata_after_imputationAnnData

AnnData object with the imputed data.

n_colsint, optional

Number of columns for the subplot grid.

return_figbool, optional

If True, returns the matplotlib Figure object for further customization. If False, shows the plot.

savebool, optional

If True, saves the figure to file.

save_namestr, optional

Name of the file to save the figure.

**kwargs

Additional keyword arguments passed to seaborn.histplot.

Returns:#

figmatplotlib.figure.Figure or None

The figure object if return_fig is True, otherwise None.
